# राजू भाई का सैलून

## Setup

1. `npm install`
2. Copy `.env.example` to `.env.local` and fill in your keys
3. `npm run dev`

## Env

See [`.env.example`](.env.example) for all variables:

- `SPOTIFY_CLIENT_ID` / `SPOTIFY_CLIENT_SECRET`
- `SPOTIFY_PLAYLIST_ID` / `NEXT_PUBLIC_SPOTIFY_PLAYLIST_URL`
- `YOUTUBE_API_KEY`
- optional `NEXT_PUBLIC_YT_MUSIC_URL`
