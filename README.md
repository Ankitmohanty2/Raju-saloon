# राजू भाई का सैलून

A barbershop vibe page with music — play Bollywood tracks one by one with volume control.

## Setup

```bash
npm install
copy .env.example .env.local
```

Add your keys in `.env.local`, then:

```bash
npm run dev
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000)
